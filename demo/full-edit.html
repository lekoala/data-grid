Data Grid

Standalone data grid web component

Full edit

The Edit action points at a real URL and is upgraded to an application-owned <dialog> from the cancelable action event. The grid never sees the form, the endpoint or the validation.

The link stays usable without JavaScript: it returns the server-rendered form fragment. Ctrl/Cmd+click keeps the native navigation. Clear a field and save to see the server validation error (422) without losing the dialog; a successful save closes it and refreshes the grid.
