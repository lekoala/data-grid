Declarative HTML facade

A native <table> inside <data-grid> is adopted as-is: columns come from <th data-field>, and when no src is configured, the <tbody> rows become the local dataset. No application JavaScript required.

Fully autonomous HTML table

Declarative row actions

Inline actions come straight from the markup: a <th data-actions> activates the column and each <td data-actions> cell is normalized into row.$actions. The actions column shares a single width across the header and every row, so no artificial overflow is created. data-value holds the typed machine value (here a number) while the cell keeps its authored presentation, and data-min-width keeps a column from being crushed.
