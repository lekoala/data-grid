Responsive

The responsive option enables the ResponsiveGrid plugin: it hides columns by priority when the grid runs out of room, and restores them when space comes back. Columns marked responsive: 0 are never hidden; higher values disappear first.

Without responsive, the grid stays a real table and scrolls horizontally when the columns don't fit.

Torture test

Priority-driven hide/show

width: —

Drag the bottom-right handle to shrink the container. City goes first, then Job Title, Company, Email, and finally the names — while ID always survives. The chevron reveals hidden values per row.

Stacked

Responsive columns + row details

width: —

Hidden columns are part of the responsive representation, so responsive-start-open shows them immediately and responsive-toggle="false" removes the second disclosure control. The remaining chevron opens application-rendered row details. Search, sort and filters still work, and an actively sorted or filtered column is never hidden.

Two controls

Responsive toggle + row details toggle

width: —

The same two plugins, but left at their defaults: responsive-toggle is true, so as soon as a column is hidden the grid renders two disclosure controls side by side. The first one reveals the hidden column values, the second one opens the row details, and each keeps its own state — expand one, the other stays as it is.

Both are the same .dg-disclosure primitive, so only their accessible names tell them apart (Show additional columns for… vs Show details for…). Tab moves from one to the other and Enter keeps the focus on the control it toggled. This configuration is supported, but the stacked one above is the recommended way to combine the two features.
