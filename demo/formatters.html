Built-in formatters

Four built-in formatters turn raw values into semantic HTML: boolean, date, datetime and number. DataGrid provides the kind of representation, Intl provides its configuration through formatOptions. The formatters never touch cell layout — the core resolves geometry (minWidth, align) from the column options and the formatter defaults. The alignment applies to the whole column: header and body cells share the same axis.

format / formatOptions

All four formatters

date renders a <time datetime> with a calendar date, datetime renders the instant (converted to Europe/Brussels here), number formats currency, percent and units through Intl.NumberFormat, and boolean renders an empty accessible mark whose check / dash shape is drawn entirely in CSS. Invalid or missing values produce an empty cell, never a guessed one: 2026-02-29 is rejected, null discounts and unshipped orders stay blank.

The locale comes from the closest lang attribute — this grid inherits the document's en. The weight column uses the unit shortcut (it implies style: "unit"), and price the currency shortcut. Each formatter also suggests a preferred filter mode: active filters with a tri-state select, numbers with typed equality, dates by exact YYYY[-MM[-DD]] periods and explicit comparisons like >2025 — while shipped (datetime) stays a plain text filter.

overrides & locale

Column geometry, granular Intl and renderCell

Explicit column options win over formatter defaults: align: "center" overrides the right-alignment that number implies (header included), align: "end" overrides the centered boolean, and minWidth raises the floor of a column. Granular Intl options (year/month/day) suppress the automatic dateStyle default. renderCell always takes full control. This grid carries lang="fr-BE", so every formatter renders in French.

price uses { currency: "EUR" } without style (the shortcut infers it), the ordered date is formatted with explicit year/month/day components, and the Tier column is a plain renderCell, not a formatter. A renderCell column carries an explicit width: autosize can only measure raw values, not rendered content.

cellClass

Conditional presentation

cellClass adds classes to body cells only — per row, at render time. It sits between format (standard semantic representation) and renderCell (full content control): the formatters stay neutral, and this page's stylesheet decides what .positive, .negative, .is-positive or .is-muted look like.

Change is a percent number with signDisplay: "exceptZero": the sign comes from Intl, the color from cellClass — zero stays neutral. The boolean column keeps its CSS-drawn mark; because it inherits currentColor, coloring the cell colors the mark. The grid itself contains no green and no red.

declarative

data-format in the markup

A column can opt into the built-in defaults with data-format (and data-align). The <tbody> becomes the local dataset: plain string values are parsed by the formatters — "129.9", "true" and ISO strings all work. Advanced Intl options stay JavaScript-only.
