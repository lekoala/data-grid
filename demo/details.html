Standalone data grid web component

Details dialog

details-display="dialog" opens row details in a modal <dialog> instead of an inline row. It works without rowDetails: the grid composes a record sheet from its own columns, so responsive values stay reachable on a narrow screen.

detailsDisplay is initial-only, like loading. One grid opens one dialog at a time; Escape and the close button end the session, and a body rerender (sort, filter, page change) leaves it open.
