Data Grid

Standalone data grid web component

Bulk actions

Bulk actions float over the grid while a selection exists. The bar follows the page or the scroll viewport, stays inside the grid, and rests on the footer at the end of the rows. Escape inside the bar clears the selection.

With "select all matching"

selectMatching: true: once the whole page is selected, the bar offers to extend the selection to every matching row. The handler then receives mode: "all" with exclusions, not a list of keys.

Select rows, then run an action.

Current page only (default)

Without selectMatching, the selection is always an explicit list of row keys.

Select rows, then run an action.

Single page, pager hidden

With autohidePager and no footer, the bar rests below the table.

Select rows, then run an action.

Inline

bulkActionsDisplay: "inline" keeps the actions in the topbar, always visible.

Select rows, then run an action.
