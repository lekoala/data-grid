Data Grid

Standalone data grid web component

Actions

Row actions are configured through the actions option.

  • Note wrap: true being assigned to the first name column

More than two actions collapse into a native anchored Popover when supported. Otherwise every action stays inline. This can be forced with collapseActions=true.

Action contract

Actions use label, intent, href, visible, disabled and an optional render function, plus class for styling hooks.

Inline editing

An email input, a select fed by editableOptions and a checkbox for booleans. The choice commits on change, and the select reflects its value as data-value so it can be styled per value. The Tag column uses an application-owned renderEditor (an input backed by a datalist that commits on change and cancels on Escape). enterMovesDown makes Enter commit then move the edit focus one row down. With four rows on a single page, autohidePager hides the pager footer.
