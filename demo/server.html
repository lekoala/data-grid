Server usage

Url should point to an endpoint that returns a json response with a data key that contains an array

It should also return a `meta` key with

  • total the total (unfiltered) number of rows.
  • filtered the total value of rows matching the current filter.

Server parameters are sent as query string and are page, pageSize, sort and filters (configurable through serializeQuery on FetchDataSource if needed).

Use src to enable a server-side data source.

To test this locally, run bun demo/server.js
