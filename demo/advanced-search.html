Advanced search

An external query builder drives the grid through its public query contract only (grid.query, setQuery(), getColumns(), getFilterOptions()) and stays in sync through querychange. The builder lives outside <data-grid>; the filter row below the headers stays independent and both converge on the same QueryState.
