Shareable URLs

Every search, sort, filter, and page change is reflected in the address bar using the same bracket notation as FetchDataSource. Copy the link, reload, or use Back/forward: the grid restores its full state. Only grid-owned params are rewritten — foreign params, the pathname, and the hash survive.
